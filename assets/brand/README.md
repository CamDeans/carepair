# Native brand raster assets

These PNGs are what **Expo / the stores** use (`app.config.ts`).

- **`app-icon.png`**, **`splash-icon.png`**, **`adaptive-icon.png`** — currently seeded from the previous `assets/images/` icons so builds stay stable.
- **`logo-mark.svg`** — copy of repo **`brand/logo-mark.svg`** for reference; in-app headers use the vector geometry in **`src/components/BrandLogo.tsx`**.

When the client approves final artwork, replace the PNGs (1024×1024 app icon, etc.) and keep **`brand/logo-mark.svg`** in sync with the raster set. See **`brand/README.md`** and **`brand/LOOP-BRAND-AND-ASSETS.md`**.
